### 🎮 게임 소개
**좀비로 폐쇄된 지역에서 살아남고 탈출하라!**
자원 수집과 제작, NPC와의 대화를 통해 점점 좁혀오는 위협 속에서 살아남는 3D 서바이벌 게임입니다.

플레이어는 자원을 수집하고, 장비를 제작하며, NPC와 대화를 통해 단서를 얻어가며 점점 좁혀오는 위협 속에서 살아남아야 합니다.

긴장감 있는 탐험, 무게 기반 인벤토리, 분기형 대사 시스템을 통해 몰입도 높은 생존 경험을 제공합니다.

---

### 📖 개요  
**Apocalypse Survival Game**은 Unity 3D로 제작된 생존 기반의 어드벤처 게임입니다.  
플레이어는 좀비가 창궐한 고립된 지역에서 탐험과 제작, NPC와의 상호작용을 통해 최종 탈출을 목표로 살아남아야 합니다.

- **게임 장르**: 생존, 어드벤처, 탐험
- **개발 환경**: Unity 2022.3.17.f1 / C#
- **플랫폼**: PC (Windows)

## 🛠️ 주요 기능

| 기능 | 설명 |
|------|------|
| 🧟 좀비 AI | 랜덤 리스폰 및 탐지 후 추격 알고리즘 구현 |
| 🏃‍♂️ 플레이어 조작 | 이동, 달리기, 점프, 아이템 습득 등 |
| 🎒 인벤토리 | 무게 기반 확장형 구조, 아이템 정보 및 드롭/사용/장착 가능 |
| 🔧 아이템 제작 | 탈출에 필요한 핵심 아이템을 수집 및 제작 |
| 🧾 NPC 대화 시스템 | NPC와 상호작용 시 카메라 전환 및 대사 출력 (스토리/퀘스트/팁 분기) |
| 🧭 UI 시스템 | 원형 미니맵 및 생존 상태(HUD) 구현 (체력, 스태미나, 배고픔 등) |
| 🧱 맵 구성 | 폐건물, 주유소, 공장, 오두막 등 생존 자원이 분포된 구조 |
